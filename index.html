maiao

A Git subcommand that turns each local commit into its own stacked pull request, so you review small changes on the forge you already use.

  • Works with GitHub, GitLab, Gitea, Forgejo and Bitbucket Cloud.
  • Tracks each commit with a Gerrit-style Change-Id, so amended commits update their pull request.
  • Rebases the stack after a merge.
